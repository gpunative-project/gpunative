# GPU Native

GPU Native is a free and open source GPU programming framework that enables GPU programming easier.

## Contributing

We welcome contributions including bug fixes, documentation, features, optimizations, and feedback. Before contributing, please check the Issues page to avoid confusion and prevent duplicate work. The issue page should provide dedicated spaces for FAQ, Discussions, and RFCs. Pull requests should be clear and well documented for all code contributions. Communication among contributors and maintainers should remain respectful.
